# 🏠 House Price Prediction using Machine Learning

## 📌 Project Overview

This project predicts house prices using Machine Learning based on various property features such as area, bedrooms, bathrooms, location, furnishing status, parking availability, and property type.

The model is built using **Random Forest Regression** and deployed using **Streamlit**.

---

## 🚀 Features

- Predict house prices instantly
- Interactive Streamlit web application
- Machine Learning Pipeline
- Automatic preprocessing
- One-Hot Encoding
- Feature Scaling
- Random Forest Regression
- User-friendly interface

---

## 📂 Dataset Features

- Area (sq ft)
- Bedrooms
- Bathrooms
- Balconies
- Age of Property
- Floor
- Total Floors
- Parking
- Location
- Furnishing Status
- Property Type

Target Variable:

- Price

## Run Locally

Clone the repository

```bash
git clone https://github.com/yourusername/HousePricePrediction.git
```

Go inside project

```bash
cd HousePricePrediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
streamlit run app.py
```
